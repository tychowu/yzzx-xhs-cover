# 示例测试结果：手把手制作小红书封面 Skill

> 本示例展示风格库驱动下的输出：4 套方案分别采用 `references/styles/` 中已学习的不同风格（示例中以风格 A/B/C/D 代称），不再套用任何内置固定视觉组合。

## 一、输入理解

- 笔记主题：从 0 到 1 制作一个“小红书封面生成 Skill”
- 目标人群：已经听过 Skill 概念、准备开始实操的 AI 初学者与内容创作者
- 核心价值：学会把封面设计经验拆成 SOP，并写进 SKILL.md 反复调用
- 可信证据：真实制作过程；参考 Claude 官方 Skill 构建指南
- 必须保留的信息：小红书封面、Skill、SKILL.md、实操属性
- 当前推断与假设：这期内容的最大点击动力不是“什么是 Skill”，而是“终于开始亲手做一个 Skill”

## 二、4 套封面方向

### 方案 1｜核心产物展示

- 风格：风格 A（示例已学风格：暗色科技感）
- 点击动机：把最终产物直接变成可识别的 3D 主体
- 主标题：手把手做一个小红书封面 Skill
- 副标题：从 0 到 1 完整实操
- 角标/可信标签：免费分享
- 信息层级：“小红书封面 Skill”最大；副标题与角标弱化
- 版式：上方粗体标题，中下部为核心产物，深底网格背景
- 画面建议：产物作为唯一主体，周围只保留少量线性图标
- 可能有效的原因：产物清楚，适合强调“做出一个可用 Skill”

### 方案 2｜完整流程拆解

- 风格：风格 B（示例已学风格：明亮纸张流程感）
- 点击动机：直接展示经验如何一步步变成 Skill
- 主标题：把封面经验变成 Skill
- 副标题：经验 → SOP → SKILL.md → 实测
- 角标/可信标签：完整流程
- 信息层级：“把封面经验变成 Skill”最大；流程卡片第二
- 版式：暖白纸张背景，上方大标题，下方编号流程卡
- 画面建议：用 3–4 张真实纸质卡表达流程，箭头连接，不堆叠代码
- 可能有效的原因：教程结构一眼可见，适合搜索与收藏导向

### 方案 3｜同一封面三次进化

- 风格：风格 C（示例已学风格：米白对比感）
- 点击动机：先看最终效果，再追问它如何被持续优化
- 主标题：同一封面，3 次进化
- 副标题：从草稿到高点击成品
- 角标/可信标签：前后对比
- 信息层级：数字 `3` 最大；“封面进化”第二；阶段图第三
- 版式：米白背景、粗体标题，下方并排草稿、优化稿、成品三张阶段卡
- 画面建议：用箭头串联三个阶段，保留少量辅助色，不使用人物
- 可能有效的原因：变化可视化，能快速建立结果期待

### 方案 4｜人物现场组装

- 风格：风格 D（示例已学风格：暗色人物故事感）
- 点击动机：用人物正在制作 Skill 的动作形成可读的故事瞬间
- 主标题：手把手做小红书封面 Skill
- 副标题：视频结尾分享
- 角标/可信标签：无
- 信息层级：主标题最大；人物动作与道具第二；副标题第三
- 版式：暗色真实场景，人物居中把文件递向镜头，标题在人物前后穿插
- 画面建议：人物动作必须由主题推导，不复制参考图中的扶额、托腮或视线
- 可能有效的原因：人物情绪、动作和道具共同表达“亲手做出并分享 Skill”

## 三、推荐方案

- 推荐：方案 4｜人物现场组装
- 推荐理由：人物正在操作与主题有关的道具，既保留“手把手实操”的现场感，也能在信息流里形成强识别；四套分别采用不同已学风格，互不雷同。
- 建议保留的最终文案：
  - 主标题：手把手做小红书封面 Skill
  - 副标题：视频结尾分享
  - 角标：无

## 四、最终制作说明

- 画布与比例：竖版 3:4
- 核心视觉中心：主标题与人物递出文件的动作
- 文字排版：主标题拆成上下两个大块，与人物形成后景—中景—前景穿插；副标题缩小放在底部
- 主体画面：居中人物把与主题有关的文件或文件夹递向镜头
- 背景与配色：暗色真实场景，主标题高对比，白色副标题
- 字体气质：粗粝手写笔刷字，保留毛边、飞白和速度感
- 素材要求：人物、文件、封面草稿或电脑；动作必须与制作主题有关
- 禁用项：复刻参考姿势、普通微笑摆拍、悬浮 UI 卡片、密集小字

## 五、验收结果

- 手机缩略图可读：通过；主标题需要分两行
- 一秒理解：通过；能理解“亲手制作并分享封面 Skill”
- 单一视觉中心：通过；主标题最醒目，人物动作和道具负责解释主题
- 可信证据真实：通过；“视频结尾分享”与实际内容一致，不夸大官方背书
- 无多余元素：通过；只保留人物、道具、主标题和一句副标题
- 封面与正文一致：通过
- 四张分别采用不同已学风格：通过
- 四张差异足够明显：通过
